# F1Network

**F1Network** è un forum dedicato agli appassionati di Formula 1, sviluppato come progetto scolastico. Il forum consente agli utenti di discutere di gare, piloti e team, offrendo una piattaforma semplice e intuitiva.

Il progetto è realizzato interamente con HTML, CSS e JavaScript per la parte frontend, mentre SQL viene utilizzato per gestire l'archiviazione dei dati e le funzionalità principali, come la registrazione degli utenti e la gestione delle discussioni. Grazie alla sua struttura leggera, F1Network è facilmente accessibile e non richiede particolari configurazioni complesse.

## Installazione e Configurazione

1. **Clona il repository**:
   ```bash
   git clone https://github.com/cliccato/F1Network.git
   ```
2. **Configura il database SQL**:
   - Importa il file SQL fornito nel tuo server SQL per creare le tabelle necessarie.
   - Se necessario, aggiorna le credenziali di connessione al database nel codice.

3. **Esegui il progetto**:
   - Apri il file `index.html` nel tuo browser per avviare il forum.
